# Plugging into the Future: An Exploration of Electricity Consumption Patterns

## Project Overview

Electricity is one of the most important resources for economic growth and sustainable development. This project analyzes electricity consumption patterns across Indian states and regions during 2019–2020, with special focus on the impact of the COVID-19 pandemic on electricity demand. Using SQL for data management and Tableau for visualization, the project provides meaningful insights into state-wise and region-wise electricity usage.


---

 Objectives

Analyze electricity consumption across Indian states.

Compare electricity usage between 2019 and 2020.

Study regional electricity consumption patterns.

Visualize the impact of COVID-19 on electricity demand.

Develop an interactive Tableau dashboard for decision-making.



---

 Technologies Used

SQL – Data Storage & Querying

Tableau Public – Data Visualization & Dashboard

CSV Dataset – Electricity Consumption Data

Microsoft Excel – Data Cleaning & Preparation

 Visualizations

The project includes the following Tableau visualizations:

1. 2019 Electricity Consumption

A filled map displaying state-wise electricity consumption during 2019, providing a baseline before the COVID-19 pandemic.

2. 2020 State Consumption

A filled map illustrating electricity consumption during 2020, highlighting changes caused by the pandemic and lockdown.

3. Total Consumption

A bar chart comparing total electricity consumption across all Indian states.

4. Usage By Region

A pie chart showing the percentage contribution of each region (NR, SR, ER, WR, NER) to India's total electricity consumption.

5. Total Region Consumption

A horizontal bar chart comparing electricity consumption among different regions of India.

---

 Key Insights

Electricity consumption differs significantly across Indian states.

Western and Southern regions contribute the highest share of electricity usage.

Industrialized and densely populated states consume more electricity.

The COVID-19 lockdown impacted electricity demand across several states.

Electricity consumption gradually recovered towards the end of 2020.
